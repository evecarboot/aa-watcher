Download hls.js from https://github.com/video-dev/hls.js/releases (the
`hls.min.js` build asset) and place it in this folder as `hls.min.js`.

It is intentionally NOT bundled/fetched from a CDN here so that no
external network request is made when corp/alliance members load this
page - keep the whole stack self-hosted for opsec.
